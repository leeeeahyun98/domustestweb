# 도무스 MES (1차 시안)

도무스(display stand / furniture 제조) 내부용 MES(제조실행시스템) 웹앱의 1차 디자인 시안입니다.

- 로그인 화면 (관리자 / 직원 역할 선택)
- 좌측 사이드바 내비게이션 (일정표에서는 사이드바가 자동으로 숨겨지고, 좌측 하단 버튼으로 다시 열 수 있음)
- 일정표 (TV/모니터 상시 게시용, 항상 다크 테마)
- 수주 등록 (발주처 건 신규 등록, 필수 항목 입력 확인 포함)
- 영업 관리 (발주처 목록 조회, 브랜드/발주처/담당자/기간 필터, 행 단위 수정 가능)
- 매출 관리 (직원 로그인 시 금액 비공개 처리)
- 경영 분석 (관리자 전용, 규칙 기반 경영 요약 포함)

> 이 버전은 **정적 화면 시안**입니다. 실제 데이터베이스 연동(로그인, 저장, 실시간 동기화)은 아직 없고,
> 모든 데이터는 예시(더미) 데이터이며 새로고침하면 초기화됩니다. 다음 단계에서 실제 데이터 저장 기능을
> 추가할 예정입니다.

## 보는 방법

이 저장소를 GitHub Pages로 공개하면 아래와 같은 주소에서 바로 웹페이지로 열어볼 수 있습니다:

```
https://<GitHub 아이디>.github.io/<저장소 이름>/
```

GitHub Pages 켜는 방법은 저장소의 Settings → Pages 메뉴에서 설정할 수 있습니다.

## 업데이트 방법

이미 만들어둔 저장소가 있다면, 이 폴더의 `index.html` 파일로 기존 파일을 덮어쓰고 다시 커밋/푸시하면
그대로 최신 화면으로 반영됩니다 (파일 이름을 그대로 `index.html`로 유지해야 합니다).
